Galaxy Map Normandy, a mod for Mass Effect 1 in the Legendary Edition (LE1)

On the galaxy map, a lit SR-1 Normandy takes the place of the orange cursor
ring, as in Mass Effect 2 and 3. It shows at cluster and system level. The
mouse works as in Mass Effect 2: hold the left button to fly toward the arrow,
and click to select. An Enter Orbit button shows when the ship is on
something you can enter. The controller keeps the normal game's controls.

You need:
- Mass Effect Legendary Edition
- the LE1 Community Patch 2.0 or later
- ME3Tweaks Mod Manager (M3)

Install:
1. Close the game.
2. Drop this 7z file on the M3 window. Or use Mod Management > Import Mod >
   Import mod from .7z/.rar/.zip/.exe/.me2mod, pick the file and click
   Import mods.
3. Select Galaxy Map Normandy in the mod library and click Apply Mod.

Uninstall: close the game. In M3, select your LE1 game and click Manage Target
to open Installation Information. Remove DLC_MOD_GalaxyMapNormandy from the
list of installed DLC mods.

Settings: pause the game, open Mod Settings and pick Galaxy Map Normandy. You
can set the ship's flight speed, turn rate, response and size. Your choices
hold for every save and apply the next time the map opens.
